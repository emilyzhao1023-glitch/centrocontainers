# Keyword research: pre-launch working set

Date: 2026-09-04

## Status

This is an evidence-bounded seed list, not a volume or CPC report. No monthly-search or bid number is included because the Google Ads account's Keyword Planner has not been used. Google's documentation states that Keyword Planner can discover ideas and report estimates, with location and language filters; those settings must be applied separately for Japan, Germany and Australia.

Official reference: https://support.google.com/google-ads/answer/7337243/use-keyword-planner?hl=en-uk

## Intent risks and negatives to validate

Search results for broad “container parts” terms commonly include retail replacement parts, repair depots and one-off modification services. That traffic may not match repeat-volume OEM purchasing. Candidate negatives for review include `used`, `repair near me`, `DIY`, `home`, `job`, `manual`, `free`, `second hand` and one-off retail terms. Do not deploy negatives until search-term evidence confirms they are unsuitable.

Google recommends using negative keywords and the search terms report to remove irrelevant traffic: https://support.google.com/google-ads/answer/6337820 and https://support.google.com/google-ads/answer/2472708

## Required account research

- Run each seed group separately for Japan, Germany and Australia.
- Use the target market's language plus English where appropriate.
- record exact location, language, network and date range beside every export.
- Separate standard-part groups from custom-manufacturing groups.
- Prefer phrase/exact testing first; expand only from qualified search terms.
- Confirm landing-page message match before enabling a campaign.
